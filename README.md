# tg-ai-notify-lite

**Claude Code пишет вам в Telegram — когда вы попросите.**

Плагин для [Claude Code](https://claude.com/claude-code). Вы говорите Claude «пришли мне в тг итог» — и через **вашего** бота в **ваш** личный чат приходит аккуратное сообщение или файл.

## Установка

```text
/plugin marketplace add belrbez/tg-ai-notify-lite
/plugin install tg-ai-notify-lite@tg-ai-notify-lite
```

Начните новую сессию и напишите Claude «пришли мне в тг тест» — он сам проведёт через создание бота и привязку чата. Подробно — [ниже](#подробная-установка--5-минут).

> [!IMPORTANT]
> **Обновление.** Сначала обновите marketplace, потом плагин — иначе останется старая версия:
> ```text
> /plugin marketplace update tg-ai-notify-lite
> /plugin update tg-ai-notify-lite@tg-ai-notify-lite
> ```
> Затем начните новую сессию. Что изменилось — в [CHANGELOG](CHANGELOG.md).

## Как выглядит

```
✅ Готово · 🧠 Claude
Парсинг цен завершён

Товаров: 1520
Время: 4 мин

#claude #WB · 28.09 14:32

🤖 @my_notify_bot → 123456789 · 📁 shop-parser · сессия 3f2a9c1e «парсинг цен»
```

Последняя строка показывает, какой бот отправил сообщение, в какой чат, из какой папки проекта и из какой сессии Claude.

- Ничего не шлёт сам — только когда вы попросили или дали задачу с отправкой в Telegram.
- Токен бота вводится на странице в браузере, а не в чате с Claude.
- Чат привязывается кодом, который бот присылает вам в Telegram: чужой человек не сможет подключиться.
- Секретные файлы (`.env`, ключи, `~/.ssh`) и тексты с ключами и токенами не отправляет.
- Можно включить тихие часы — ночью сообщения будут приходить без звука, кроме срочных. По умолчанию выключены.

## Что нужно

- Claude Code — вкладка Code в десктопном приложении Claude или терминал.
- **Node.js 22 или новее** — [nodejs.org](https://nodejs.org), версия LTS. Проверка: `node --version`.
- Аккаунт Telegram.

## Подробная установка — 5 минут

### 1. Создайте бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя и адрес бота (адрес должен заканчиваться на `bot`).
3. Скопируйте **токен** — строку вида `123456789:AAH…`. Пока никуда его не вставляйте.

Заведите **отдельного** бота только для этого плагина. Если тот же бот используется другой программой, привязка не сработает.

### 2. Установите плагин

В Claude Code выполните две команды:

```
/plugin marketplace add belrbez/tg-ai-notify-lite
```

```
/plugin install tg-ai-notify-lite@tg-ai-notify-lite
```

Если Claude Code при установке спросит токен — можно вставить его сразу или пропустить: дальше Claude даст страницу, где это сделать проще. Тихие часы можно оставить по умолчанию.

Начните **новую сессию** Claude Code — плагин подключается при её старте.

### 3. Первое сообщение

Напишите Claude:

> пришли мне в телеграм тест

Дальше всё по подсказкам:

1. **Токен** (если ещё не задан). Claude даст ссылку «⚙ Открыть страницу настройки бота». На странице — пошаговая инструкция, как создать бота в @BotFather, и поле для токена. Вставьте токен, нажмите «Сохранить» и напишите Claude «готово».
2. **Привязка чата.** Claude даст ссылку «▶ Запустить Telegram-бота» — перейдите по ней и нажмите **Start**. Писать Claude ничего не нужно: он ждёт нажатия до 3 минут. Не успели — он попросит написать «нажал», когда нажмёте.
3. **Код.** Бот пришлёт вам в Telegram 6 цифр — напишите их Claude.
4. Бот пришлёт «✅ Этот чат привязан…» с кратким списком того, что можно просить, а следом — ваше сообщение.

Привязка делается один раз и работает во всех сессиях, в том числе после перезапуска.

## Как пользоваться

Просто попросите:

- «пришли в тг итог по задаче» — подходят «тг», «tg», «телега», «телеграм»
- «сделай … и в конце отправь итог в тг» — Claude выполнит задачу и сам пришлёт итог, даже если что-то не получилось
- «до конца сессии после каждой задачи пиши мне в тг» — итог после каждой задачи в этом разговоре
- «скинь мне в телегу файл отчёта C:\Users\…\report.xlsx»
- «каждый час присылай в телеграм сводку по логам» — для регулярной задачи (`/loop` или задача по расписанию в десктопном приложении)
- «пришли в тг без звука…» / «это срочно, пришли в тг…»

Если вы дали сессии название через `/rename` и хотите видеть его в сообщениях — скажите его Claude. Иначе Claude сам коротко назовёт разговор.

## Настройки

| Что | Как |
|---|---|
| Задать или сменить токен (бота) | Скажите Claude «смени токен telegram-бота» — он даст ссылку на страницу настройки. Перезапуск не нужен |
| Тихие часы (по умолчанию выключены) | `/plugin` → tg-ai-notify-lite → настройки: `HH:MM-HH:MM` (например `23:00-08:00`) или `off`, затем новая сессия |
| Итог после каждой задачи во всех сессиях | добавьте в `CLAUDE.md` проекта или `~/.claude/CLAUDE.md` строку «После завершения каждой задачи присылай мне краткий итог в Telegram» |
| Перепривязать к другому чату | команда `/tg-ai-notify-lite:rebind` |
| Посмотреть, куда привязан | попросите «покажи статус telegram-плагина» |

Токен, сохранённый на странице настройки, главнее токена из `/plugin`. Если вы поменяли бота, плагин сам попросит привязать чат заново.

## Задачи по расписанию и разрешения

Каждый вызов инструмента плагина Claude Code по умолчанию подтверждает у вас. Для задач, которые работают без вас, **заранее** можно разрешить только эти инструменты — добавьте в `~/.claude/settings.json`:

```json
{
  "permissions": {
    "allow": [
      "mcp__plugin_tg-ai-notify-lite_telegram__send_telegram_message",
      "mcp__plugin_tg-ai-notify-lite_telegram__telegram_status"
    ]
  }
}
```

Привязка и токен в задаче без вас не настраиваются: сначала сделайте это один раз в обычной сессии. `send_telegram_file` заранее не разрешайте — пусть Claude каждый раз спрашивает, какой файл отправляет.

Облачные задачи Claude (`/schedule`, routines) работают на серверах Anthropic и **не видят** плагин на вашем компьютере — для них плагин не подходит.

## Что-то не работает

| Симптом | Что делать |
|---|---|
| Claude говорит, что инструментов плагина нет | Начните новую сессию. Если не помогло — нет Node.js 22+: для десктопного приложения `node` должен быть в системном PATH (установщик с nodejs.org это делает; nvm-windows и fnm — не всегда). Перезапустите Claude Code |
| «Токен бота не задан» / «выглядит неправильно» / ошибка 401 | Попросите Claude открыть страницу настройки и вставьте токен из @BotFather заново |
| Страница настройки не открывается | Она работает 15 минут и только на этом компьютере. Попросите Claude дать новую ссылку |
| «Бот уже используется другим приложением» / 409 | Этого бота читает другая программа. Создайте отдельного бота для плагина |
| «Бот завален сообщениями» | Создайте нового бота и введите его токен |
| «Ссылка привязки истекла» | Ссылка действует 10 минут — попросите Claude повторить отправку, он выдаст новую |
| «Код не совпал» | Перепишите 6 цифр из последнего сообщения бота. После 5 ошибок привязку нужно начать заново |
| Код не пришёл | Проверьте, что нажали Start в нужном боте и он не заблокирован; попросите Claude проверить ещё раз |
| 403 «bot was blocked by the user» | Разблокируйте бота в Telegram и нажмите Start |
| «Не удалось связаться с api.telegram.org» | Проверьте интернет; в некоторых сетях Telegram API недоступен |
| «НЕ_ПРИВЯЗАН» в задаче по расписанию | Проведите привязку один раз в обычной сессии |

## Безопасность

- **Токен.** Вводится на локальной странице `http://127.0.0.1:…` со случайным адресом, которая работает 15 минут и закрывается после сохранения; в переписку с Claude он не попадает. Хранится в файле `token.json` в папке данных плагина внутри вашей папки пользователя (`~/.claude/plugins/data/…`); отправить этот файл в Telegram плагин не даст. Если ввести токен через `/plugin`, он хранится в системном хранилище паролей. Токен вырезается из всех ответов и сообщений об ошибках. Если токен когда-нибудь попал в чат или на скриншот — выпустите новый в @BotFather (`/revoke`).
- **Привязка.** Сообщения уходят только в привязанный личный чат. Чтобы привязать чат, нужен 6-значный код, который бот присылает в этот чат; код хранится только в памяти плагина, не на диске. Если по ссылке нажал Start кто-то чужой, код получит он, а не вы, — и без вас привязку не завершит. После 5 неверных кодов привязка отменяется.
- При перепривязке прежний чат получает уведомление.
- В журнале плагина (`~/.claude/plugins/data/…/journal.log`) хранятся только время, тип и размер отправленного — без текста сообщений.

Подробно о данных и о том, как сообщить об уязвимости, — [SECURITY.md](SECURITY.md).
