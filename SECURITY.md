# Безопасность и данные

## Поддерживаемые версии

Исправления выходят в последней версии на `main`. Обновитесь:

```bash
claude plugin marketplace update tg-ai-notify-lite
claude plugin update tg-ai-notify-lite@tg-ai-notify-lite
```

## Как сообщить об уязвимости

Не открывайте публичный issue. Используйте приватное сообщение через GitHub: вкладка **Security** → **Report a vulnerability** в этом репозитории.

Опишите:

- что не так и как это воспроизвести;
- что может сделать злоумышленник;
- если есть — как исправить.

## Какие данные куда уходят

| Данные | Где хранятся | Куда уходят |
|---|---|---|
| Токен бота | Системное хранилище паролей (если введён через `/plugin`) или `token.json` в папке данных плагина (если введён на странице настройки) | Только в `api.telegram.org` — в адресе запросов к Bot API |
| Привязка (chat_id, имя и username в Telegram, ID сессии Claude) | `binding.json` в папке данных плагина | Никуда |
| Код привязки | Только в памяти MCP-сервера, на диск не пишется | Только в ваш чат Telegram |
| Текст сообщений и файлы | Не хранятся | Только в привязанный чат через ваш бот |
| Журнал отправок | `journal.log` в папке данных плагина: время, тип, размер, ID сессии — без текста | Никуда |

Папка данных плагина — `~/.claude/plugins/data/tg-ai-notify-lite-tg-ai-notify-lite/`. Плагин не собирает аналитику и не обращается ни к каким серверам, кроме `api.telegram.org`. Страница настройки токена работает только на `127.0.0.1` вашего компьютера.

## Защита

- Сообщения отправляются только по явной просьбе пользователя или в заданной им задаче.
- Токен вырезается из всех ответов, ошибок и логов; в чат с Claude его вводить не нужно.
- Привязка чата требует 6-значного кода, который бот присылает в этот чат; после 5 неверных кодов привязка отменяется. При перепривязке прежний чат получает уведомление.
- Секретные файлы (`.env`, ключи, `~/.ssh`, папка данных плагина и другие) и тексты, похожие на ключи и токены, не отправляются.

Поведение также зависит от Claude Code и от того, какие разрешения вы дали инструментам плагина.
