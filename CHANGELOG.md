# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.2.1] — 2026-10-05

### Изменено
- После ссылки на бота Claude сам ждёт нажатия Start до 3 минут — писать «нажал» не нужно; просит, только если не дождался.
- Ссылки «▶ Запустить Telegram-бота» и «⚙ Открыть страницу настройки бота» показываются крупно, с понятным призывом.
- Страница настройки пошагово объясняет, как создать бота в @BotFather.
- Тихие часы по умолчанию **выключены**; включаются в настройках плагина.
- Скилл срабатывает на «tg», «тг», «телега», «телеграмм» и на просьбы прислать итог после выполнения задачи.

### Добавлено
- В сообщении «✅ Этот чат привязан…» — краткий список того, что можно просить Claude.
- Правила для агентов (`AGENTS.md`), руководство разработчика, CONTRIBUTING, SECURITY, CI на GitHub Actions.

## 0.2.0 — 2026-10-02

### Изменено
- Привязка чата подтверждается **6-значным кодом**, который бот присылает в Telegram, вместо окна подтверждения Claude Code: во вкладке Code десктопного приложения окно не показывалось и привязка была невозможна.

### Добавлено
- Инструмент `telegram_setup`: локальная страница в браузере для ввода токена бота — без консоли и без перезапуска сессии. Токен в настройках плагина стал необязательным.

## 0.1.0 — 2026-09-28

### Добавлено
- Первая версия: отправка сообщений и файлов в привязанный личный чат Telegram в едином формате с подписью (бот, чат, папка проекта, сессия Claude), привязка по ссылке со Start, тихие часы, защита токена и секретных файлов.
